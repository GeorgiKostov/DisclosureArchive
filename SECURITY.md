# Security Policy

DisclosureArchive is a static public archive/search site backed by generated JSON.

## Reporting a vulnerability

Please report security issues through the project contact page:

https://disclosurearchive.org/contact.html

Do not include sensitive exploit details in public screenshots or social posts before
the issue has been reviewed.

## Scope

In scope:

- The static public site export.
- Repository scripts used to publish the public site.
- Leaks of local/private paths or generated archive data into publishable artifacts.

Out of scope:

- The original government-hosted source files.
- Third-party CDNs or media hosts linked by the archive.
- Claims made inside source documents.
